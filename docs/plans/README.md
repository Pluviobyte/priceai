## 已确定的核心决策

- 产品最终覆盖四个频道：卡网订阅、官方订阅、官方 API、中转 API。
- 第一版只做卡网订阅数据底座和购买决策前台，其余频道分阶段加入。
- 来源发现与事实采集分离：Grok、X、搜索和其他聚合站只负责提供候选线索，正式报价优先回到原店铺核验。
- 采用多适配器架构，不开发一个试图适配所有网站的“万能爬虫”。
- 原始采集事实、商品分类结果与正式发布报价分层保存。
- 采集失败不能等同于缺货，部分快照不能批量清空旧商品。
- 低价、库存冲突和分类低置信度商品必须隔离，不得直接参与最低价。
- 前台必须展示原始标题、原站链接、最后确认时间、数据新鲜度与风险事实。
- 商家投稿只进入候选池，经过 URL 安全检查、试采集和审核后才能上线。
- 广告、赞助和 affiliate 必须显著标识，不能影响自然排序。

## 建议阅读顺序

产品与运营先阅读 PRD 和路线图；工程实现先阅读采集架构和数据模型；开始开发前，四份方案应共同完成一次范围评审。
