# 功能清单与优先级

> 目标：功能层面对标 PriceAI。  
> 优先级：P0 为首版必须，P1 为形成完整竞争力，P2 为后续扩展。

## 13. 首版 P0 边界

首版必须形成下面这个完整闭环：

```text
提交或录入店铺
→ URL 安全检查
→ 识别 3 类发卡系统
→ 试采集和人工审核
→ 定时完整抓取
→ 原始快照与失败保护
→ 商品分类和风险抽取
→ 异常隔离
→ 原子发布
→ 首页 / 商品页 / 商家页
→ 用户举报和后台纠正
```

首版暂不包含：官方 API、中转 API、论坛、AI 新闻、在线聊天、自动购买、需要登录或验证码的来源。

## 14. P0 验收指标

- 3 类适配器能够稳定采集 30–50 个来源；
- 覆盖 10–15 个标准权益产品；
- 价格解析抽样准确率不低于 99.5%；
- 任何采集失败都不会清空上一版有效数据；
- 部分快照不能批量下架未出现的旧商品；
- 库存冲突、异常价、过期报价不参与最低价；
- 商品改价不会生成新的商品身份；
- 每条公开报价都有原始标题、原站 URL 和最后确认时间；
- 每次人工纠错都有审计记录；
- 最新发布版本能够回滚。
