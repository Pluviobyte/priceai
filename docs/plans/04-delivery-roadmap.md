# 开发路线图与验收标准

## 总体策略

先建立正确、可审计的数据底座，再做大规模来源覆盖。第一版不追求复制 PriceAI 的全部数据量，而要完整打通“发现 → 采集 → 校验 → 分类 → 发布 → 纠错”的闭环。

## 阶段 0：工程与产品基线

### 交付

- Monorepo 与环境配置；
- Next.js Web/管理后台；
- PostgreSQL、Redis、对象存储；
- Worker 与队列骨架；
- 数据 Schema、迁移、种子数据；
- 登录与管理员权限；
- 基础日志、指标与错误追踪。

### 验收

- 本地一条命令启动主要服务；
- 开发、测试、生产环境隔离；
- 数据库迁移可重复执行；
- Worker 不持有前台不需要的敏感权限。

## 阶段 1：卡网数据底座

### 范围

- Shop API / LDXP；
- Kami / 异次元；
- 独角数卡；
- 30–50 个代表性店铺；
- ChatGPT、Claude、Gemini、Grok；
- 10–15 个核心权益产品。

### 交付

- 来源候选、投稿和审核；
- 发卡系统 Probe 与身份解析；
- 3 个适配器；
- 采集运行、原始快照和对象存储；
- 分页完整性、数量和字段校验；
- 部分失败、旧快照保护；
- 商品规则分类与人工审核；
- staging 与原子发布；
- 来源和异常管理后台。

### 验收

- 价格解析抽样准确率 ≥ 99.5%；
- 库存冲突不会进入最低价；
- 完整采集失败不会清空旧数据；
- 部分快照不会批量标记旧商品下架；
- 商品改价不会产生新商品身份；
- 同一来源任务不会并发重叠；
- 每条报价可回放到原始 payload。

## 阶段 2：卡网比价前台

### 交付

- 首页、平台页、商品详情页、商家页；
- 搜索和筛选；
- 最低有货价与质保最低价；
- 原始标题、原站链接和确认时间；
- 库存和数据新鲜度分开显示；
- 风险事实；
- 渠道提交、举报纠错；
- 数据说明、免责声明和广告标识。

### 验收

- 不同交付方式不会错误争夺同一个默认最低价；
- 过期报价默认不参与最低价；
- 用户能在两步内从标准商品进入原站；
- 每个公开数值均可看到来源和时间；
- 移动端可完成搜索、筛选和跳转。

## 阶段 3：官方订阅与价格历史

### 交付

- App Store 多地区采集；
- Google Play 公开区间；
- 官网直购价格；
- 汇率版本与人民币估算；
- 官方套餐映射；
- 价格与库存历史；
- 价格变化和补货事件；
- 降价/补货提醒基础设施。

### 验收

- 官方价和第三方卡网价分频道；
- 未精确匹配 SKU 的区间不参与最低价；
- 每条地区价保留证据 URL、原币和汇率日期；
- 可查看任一报价的历史变化。

## 阶段 4：来源增长与运营闭环

### 交付

- Grok/X、搜索和社区候选发现；
- 聚合站 feed 只作覆盖缺口与来源发现；
- 自动 Probe 和采集器待办；
- Schema drift 告警；
- 分类规则版本、回归测试；
- 商家退出、纠错和投诉机制；
- 自适应调度、熔断和主机限流；
- 公开采集健康页。

### 验收

- 候选来源不会未经审核进入正式库；
- 适配器字段变化能在污染线上数据前告警；
- 人工纠错能沉淀为规则并回放历史；
- 连续失败来源自动退避和降级。

## 阶段 5：官方 API

### 交付

- OpenAI、Anthropic、Google 等官方 API 来源；
- 输入、输出、缓存、批量价格；
- 图片、视频、音频计费单位；
- 免费层、套餐额度和速率限制；
- 文档版本和核验时间。

### 验收

- 所有价格直接链接官方文档；
- 计费维度不兼容的模型不做虚假统一排序；
- 价格和套餐额度变更留历史。

## 阶段 6：中转 API 与稳定性监控

### 交付

- 中转站目录与资料审核；
- 公开模型目录/倍率采集；
- 站点公开监测数据；
- 平台主动可用性和延迟探测；
- 7 日成功率、延迟和事件时间线；
- 模型级和站点级证据来源区分。

### 验收

- 价格来源与稳定性来源独立展示；
- 没有样本时不伪造可用率；
- 主动探测不发送用户数据，不绕过登录/WAF；
- 探测频率、样本数和失败原因可审计。

## 阶段 7：规模化与商业化

### 交付

- 数百至上千来源；
- 商家标准 Feed 规范；
- “商家直连数据”证据标记；
- 数据 API 与调用配额；
- 赞助位、联盟链接和商业关系披露；
- 数据质量与覆盖率报表。

### 验收

- 商业付费不改变自然排序；
- Feed 数据仍经过异常校验；
- 单一共享发卡平台故障不会拖垮整轮任务；
- 发布过程可回滚到上一 generation。

## 优先级总表

| 优先级 | 必须完成 |
|---|---|
| P0 | 数据底座、3 个适配器、状态机、后台、卡网前台、投稿与举报 |
| P1 | 官方地区价、价格历史、提醒、来源增长和公开健康页 |
| P2 | 官方 API、中转 API、稳定性监控和公共数据服务 |

## 首版暂缓事项

- 社区论坛；
- AI 新闻与公告聚合；
- 在线多模型聊天；
- 原生移动 App；
- Elasticsearch；
- 黑箱式商家信用评分；
- 自动执行购买或代充；
- 需要登录、验证码或绕过 WAF 的数据源。

## 发布前检查清单

- 数据来源、更新时间和证据链接可见；
- 隐私政策、服务条款、免责声明完整；
- 投稿 URL 的 SSRF 防护通过测试；
- 广告、赞助与 affiliate 清晰标注；
- 异常低价、库存冲突和过期数据不参与默认排序；
- 采集失败不会破坏上一版可用数据；
- 后台所有人工修改有审计记录；
- 可以从最新版本快速回滚上一发布版本；
- 没有复制 PriceAI 的品牌和受保护视觉资产。
