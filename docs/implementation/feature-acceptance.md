## 验收边界

- 代码功能为 125/125；其中 SRC-08、SRC-09、STD-10 必须配置外部服务密钥。
- 当前真实启用来源为 4 个，已经覆盖四类采集路径，但“30–50 个来源”和 99.5% 人工抽样准确率是上线运营验收指标，不应伪称已由本地样本证明。
- 本轮未新增自动化行为测试，因为测试 seam 尚未获得确认；已执行真实 HTTP、数据库、公开上游、并发租约、角色拒绝、发布回滚和备份恢复冒烟。
